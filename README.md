# 翻訳

更新日: 2026-10-07

DeepL のテキスト翻訳画面に近いページです。翻訳そのものは DeepL API で行います。APIキーは画面右上の「APIキー」から入力でき、そのブラウザにだけ保存されます。未入力のときは、サーバーの環境変数 `DEEPL_API_KEY` を使います。

## できること

- 左側に原文を入力すると、入力の途中から翻訳します
- 原文の言語は初期状態で自動検出です
- 訳文の言語は初期状態で日本語です
- 原文と訳文をそれぞれコピーできます
- 原文と訳文の言語を入れ替えられます

無料プランのキー（末尾が `:fx`）は `api-free.deepl.com`、それ以外は `api.deepl.com` を使います。

## ローカルで動かす

```bash
npm install
copy .dev.vars.example .dev.vars
```

`.dev.vars` に DeepL の APIキーを書くと、画面でキーを入れなくても翻訳できます。画面で入力したキーがある場合は、そちらを優先します。

```bash
npm run dev
```

http://localhost:8788 を開きます。
